Not An Insider
(Just Lucky)

A prediction-market prototype that checks identity and conflicts of interest before a trade goes through, then records every decision in an auditable trail.

  • Next.js
  • TypeScript
  • Supabase
  • GoDaddy ANS
Project repository ↗
Behind the build +

Browser-signed trades pass through signature, replay, identity, affiliation, balance, and timing checks. Decisions are recorded in a hash-chained audit log, including blocked attempts.

The demo combines GoDaddy’s Agent Name Service, Capital One’s Nessie sandbox, and Supabase. Affiliation checks currently rely on declared information.
